# PRD: 인하런 (InhaLearn)

## 목표
고등학생이 10분 안에 프로그래밍의 핵심 개념(순서, 반복)을 재미있게 체험하고, 코딩에 대한 긍정적 첫 경험을 얻는다.

## 사용자
- **주 대상**: 고등학교 1-2학년 (프로그래밍 경험 없음)
- **사용 환경**: 모바일 (핸드폰 브라우저)
- **사용 맥락**: 인하대 전공 멘토단 실습 수업 (약 10분)
- **기대 수준**: 클릭만으로 학습 가능, 타이핑 불필요

## 핵심 기능

### 1. 온보딩 (Phase 1 추가 ⭐)
- **랜딩 페이지**: 프로젝트 소개 + 인덕이 캐릭터
- **20초 인터랙티브 데모**: 블록 1개 추가 → 실행 → 성공 체험
- **3컷 설명**: 블록 선택 → 추가 → 실행 과정 시각화
- 즉시 시작 가능 (로그인 불필요)

### 2. 블록 코딩 시스템
- 상하좌우 이동 블록 (⬆️⬇️⬅️➡️)
- 반복 블록 (🔁 N번 반복, 중첩 가능)
- 스타일 블록 (🎨 색깔, ✏️ 펜)
- 클릭으로 추가/제거 (드래그 불필요)
- 코드 실행 → 인덕이(오리 캐릭터)가 캔버스에서 애니메이션으로 이동

### 3. 6개 핵심 스테이지 (Phase 1 개선 ⭐)
- **스테이지 0**: 튜토리얼 (30초) - 블록 추가/실행 기본 조작
- **스테이지 1**: 계단 오르기 (1분) - 두 방향 조합
- **스테이지 2**: 반복의 발견! (2분) ⭐ **핵심** - 개선된 "귀찮음 전략"
- **스테이지 3**: 사각형 그리기 (1.5분) - 반복 활용
- **스테이지 4**: 미로 탈출 (2분) - 복잡한 문제 해결
- **스테이지 5**: 자유 창작 (1분) - 배운 것 응용

**보너스 스테이지** (선택, Phase 2):
- ⭐ 지그재그 도전 (더 어려운 패턴)
- ⭐ 무지개 그리기 (색깔 블록 활용)

### 4. 실행 제어 (Phase 1 추가 ⭐)
- **속도 조절**:
  - 보통 (0.3초/칸, 기본)
  - 빠르게 (0.1초/칸)
  - 건너뛰기 (즉시 결과)
- **에러 피드백 개선**:
  - "3번째 블록에서 벽에 부딪혔어요!" (구체적 위치)
  - 문제 블록 시각적 강조
  - 빠른 수정 버튼 ([해당 블록 삭제])

### 5. 진행 상황 표시 (Phase 1 추가 ⭐)
- **학생 화면 상단에 크게 표시**:
  - 현재 스테이지 (3/6)
  - 획득 별 개수 (⭐⭐⭐ 9개)
- 선생님이 멀리서도 한눈에 진행도 확인 가능
- 돌아다니며 개별 지도 용이

### 6. 게이미피케이션
- 별점 시스템 (⭐⭐⭐ / ⭐⭐ / ⭐)
- 진행률 표시 (6개 중 몇 개 완료)
- 힌트 시스템 (30초 후 제공, 선택적 사용)
- 완주 축하 화면 + 작품 공유 (URL 복사)

## 핵심 교육 전략: "귀찮음 → 발견" (Phase 1 개선 ⭐)

**스테이지 2 개선 방식**:

### 문제점 (기존)
- 블록 10개 수동 추가 → 너무 지루해서 이탈 위험

### 해결책 (개선)
1. **블록 5개로 줄이기** (10개 → 5개)
   - 격자판: 5칸 (부담 감소)

2. **능동적 발견 유도**:
   ```
   블록 5개 추가 완료 시:

   ┌─────────────────────────┐
   │  💡 발견!                │
   │                         │
   │  같은 블록을 계속 쓰고   │
   │  있네요...              │
   │                         │
   │  더 쉬운 방법이          │
   │  있을까요?              │
   │                         │
   │  [힌트 보기] [계속하기]  │
   └─────────────────────────┘
   ```

3. **선택권 부여**:
   - "힌트 보기" 선택 시 → 반복 블록 소개
   - "계속하기" 선택 시 → 스스로 발견 기회

4. **비교 화면**:
   ```
   ❌ 이전 방법: 5줄
   1. ➡️ 오른쪽
   2. ➡️ 오른쪽
   3. ➡️ 오른쪽
   4. ➡️ 오른쪽
   5. ➡️ 오른쪽

   ✅ 반복 사용: 2줄
   🔁 5번 반복
     └─ ➡️ 오른쪽

   60% 줄어들었어요! 🎉
   ```

**효과**:
- ✅ 이탈률 감소 (5개면 부담 적음)
- ✅ 능동성 증가 (선택권)
- ✅ 교육 효과 유지 (반복문 필요성 체감)

## Phase 1 (MVP) - 필수 기능

### 구현 범위
- ✅ 랜딩 페이지 + 20초 데모
- ✅ 6개 핵심 스테이지 (0-5)
- ✅ 기본 블록 (이동 4개, 반복 1개)
- ✅ 실행 속도 조절
- ✅ 개선된 에러 피드백
- ✅ 학생 화면 진행 표시

## Phase 2 (완성) - 향상 기능

### 추가 기능
1. **교사 대시보드** (Firebase 활용)
   - 실시간 학생 진행도 모니터링
   - room 코드로 반 구분
   - 익명 접속 (개인정보 불필요)
   - Firebase Realtime Database (무료 티어)

2. **PWA 오프라인 지원**
   - Service Worker 캐싱
   - 학교 와이파이 불안정 대비
   - 홈 화면 추가 지원

3. **뱃지 시스템**
   - 🎓 첫 발견 (반복 블록 첫 사용)
   - 🌟 완벽주의자 (모든 스테이지 ⭐⭐⭐)
   - ⚡ 스피드런 (5분 안에 완주)
   - 🎨 아티스트 (자유 창작 완료)

4. **보너스 스테이지**
   - 지그재그 패턴
   - 무지개 그리기
   - 복잡한 미로

5. **스토리텔링 강화**
   - 인덕이 보물찾기 스토리
   - 엔딩 애니메이션
   - 인증서 다운로드

## 디자인

### 브랜딩
- **캐릭터**: 인덕이 (인하대 오리 마스코트)
- **컬러**: 인하대 스카이블루 (#0099CC) 중심
- **톤앤매너**: 친근하고 재미있는, 학생들이 만든 프로젝트 느낌
- **공식 느낌 배제**: 인하대 공식 사이트로 오해받지 않도록

### UI 원칙
- **모바일 우선**: 세로 모드 최적화, 큰 터치 타겟 (44px+)
- **즉각적 피드백**: 터치 시 scale/색상 변화, 실행 즉시 애니메이션
- **단순함**: 복잡한 메뉴 없음, 한 화면에 모든 것
- **격려**: "잘했어요!", "거의 다 왔어요!" 같은 긍정 메시지

### 색상
- Primary: 스카이블루 (#0099CC)
- Background: 화이트 (#FFFFFF)
- Text: 검정/그레이 (#212121 / #9E9E9E)
- Success: 초록 (#4CAF50)
- Warning: 오렌지 (#FF9800)
