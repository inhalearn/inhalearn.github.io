# 인하런 레벨 설계

## 📊 전체 구조 (Phase 1 개선)

```
총 6개 핵심 스테이지 (0-5)
예상 소요 시간: 약 8분 (여유 있음)

스테이지 0: 튜토리얼 (30초)
스테이지 1: 계단 오르기 (1분)
스테이지 2: 반복의 발견! ⭐ 핵심 (2분) - 개선된 방식
스테이지 3: 사각형 그리기 (1.5분)
스테이지 4: 미로 탈출 (2분)
스테이지 5: 자유 창작 (1분)

보너스 스테이지 (Phase 2):
⭐ 지그재그 도전
⭐ 무지개 그리기
```

## 🎮 스테이지별 상세 설계

### 스테이지 0: 만나서 반가워!

**학습 목표**: 블록 추가 및 실행 방법 익히기

**스토리**: "안녕! 나는 인하대 마스코트 인덕이야! 함께 코딩을 배워보자!"

**격자판**: 5×3
```
🦆 ─────→ ⭐
(0,0)     (2,0)
```

**제공 블록**:
- `➡️ 오른쪽으로` (이동 블록만)

**미션**: 인덕이를 별까지 이동시키기

**정답**:
```
1. ➡️ 오른쪽으로
2. ➡️ 오른쪽으로
```

**성공 조건**:
- 인덕이가 별 위치 (2,0)에 도달

**힌트**:
- 30초 후: "아래 블록을 눌러서 코드에 추가해보세요"
- 60초 후: "오른쪽 블록을 2번 추가하면 돼요!"

**획득 별**:
- ⭐⭐⭐: 힌트 없이 클리어
- ⭐⭐: 힌트 1개 사용
- ⭐: 힌트 2개 사용

**학습 포인트**:
- 명령어는 위에서 아래로 순차 실행
- 블록을 추가하고 실행하는 기본 조작법

### 스테이지 1: 계단 오르기

**학습 목표**: 두 가지 방향 조합하기

**스토리**: "중앙도서관 계단을 올라가보자!"

**격자판**: 5×5
```
      ⭐ (2,2)
      │
    ┌─┘
    │
🦆 ─┘
(0,0) → (1,0) → (1,1) → (2,1) → (2,2)
```

**제공 블록**:
- `➡️ 오른쪽으로`
- `⬆️ 위로`

**미션**: L자 모양 계단 오르기

**정답**:
```
1. ➡️ 오른쪽으로
2. ⬆️ 위로
3. ➡️ 오른쪽으로
4. ⬆️ 위로
```

**성공 조건**:
- 인덕이가 별 위치에 도달
- 벽에 부딪히지 않음

**힌트**:
- 40초 후: "오른쪽 → 위 → 오른쪽 → 위 순서로 움직여요"

**획득 별**:
- ⭐⭐⭐: 4개 블록으로 해결
- ⭐⭐: 5-6개 블록으로 해결
- ⭐: 도착만 하면 됨

**학습 포인트**:
- 여러 방향을 조합할 수 있음
- 순서가 중요함

---

### 스테이지 2: 반복의 발견! ⭐ 핵심 스테이지 (Phase 1 개선)

**학습 목표**: 반복문의 필요성을 능동적으로 발견하기

**스토리**: "인하대 정문에서 본관까지 길을 걸어보자..."

**격자판**: 7×3 (가로 길이 단축: 10칸 → 5칸)
```
🦆 ──────────→ ⭐
(0,1)       (5,1)
```

**제공 블록 (1단계)**:
- `➡️ 오른쪽으로` (반복 블록 없음!)

**미션 1단계**: 오른쪽 블록을 5개 추가해서 이동

**학생 경험**:
```
1. ➡️ 오른쪽으로
2. ➡️ 오른쪽으로
3. ➡️ 오른쪽으로  ← "음... 계속 똑같네?"
4. ➡️ 오른쪽으로
5. ➡️ 오른쪽으로  ← "완료!"
```

**중간 피드백 (개선 ⭐)**:
```
블록 5개 추가 완료 시:

┌─────────────────────────┐
│  💡 발견!                │
│                         │
│  같은 블록을 계속 쓰고   │
│  있네요...              │
│                         │
│  더 쉬운 방법이          │
│  있을까요?              │
│                         │
│  [힌트 보기] [계속하기]  │
└─────────────────────────┘
```

**선택 A: "힌트 보기"**
```
┌─────────────────────────┐
│  💡 힌트                 │
│                         │
│  🔁 반복 블록을 사용하면 │
│  더 짧게 쓸 수 있어요!   │
│                         │
│  [새 블록 사용하기]      │
└─────────────────────────┘
```

**선택 B: "계속하기"**
- 학생이 스스로 발견할 기회
- 다음 스테이지 진행

**제공 블록 (2단계)**: 새로운 블록 등장!
```
🔁 반복하기
   횟수: [2] [3] [4] [5]
   └─ (블록 넣는 영역)
```

**미션 2단계**: 반복 블록을 사용해서 같은 목표 달성

**정답**:
```
🔁 5번 반복
  └─ ➡️ 오른쪽으로
```

**비교 화면**:
```
┌─────────────────────────┐
│  📊 코드 비교            │
│                         │
│  ❌ 이전 방법: 5줄      │
│  1. ➡️ 오른쪽           │
│  2. ➡️ 오른쪽           │
│  3. ➡️ 오른쪽           │
│  4. ➡️ 오른쪽           │
│  5. ➡️ 오른쪽           │
│                         │
│  ✅ 반복 사용: 2줄      │
│  🔁 5번 반복            │
│    └─ ➡️ 오른쪽         │
│                         │
│  60% 줄어들었어요! 🎉   │
│                         │
│  [다음 스테이지로 →]    │
└─────────────────────────┘
```

**획득 별**:
- ⭐⭐⭐: 반복 블록 사용
- ⭐⭐: 수동 5개로 해결
- ⭐: 도착

**학습 포인트**: ⭐⭐⭐ 가장 중요!
- ✅ 이탈률 감소 (5개로 줄임)
- ✅ 능동적 발견 (선택권 부여)
- ✅ 프로그래밍의 본질 이해 ("귀찮은 일을 줄이는 것")

### 스테이지 3: 사각형 그리기

**학습 목표**: 반복문 활용하기

**스토리**: "운동장 트랙을 한 바퀴 돌아보자!"

**격자판**: 7×7
```
🦆→→→→┐
↑     ↓
↑     ↓
↑     ↓
└←←←←┘⭐
```

**제공 블록**:
- `➡️ 오른쪽으로`
- `⬇️ 아래로`
- `⬅️ 왼쪽으로`
- `⬆️ 위로`
- `🔁 반복하기`

**미션**: 정사각형 그리기 (4×4 크기)

**정답 (예시)**:
```
🔁 4번 반복
  ├─ 🔁 4번: ➡️ 오른쪽
  ├─ 🔁 4번: ⬇️ 아래
  ├─ 🔁 4번: ⬅️ 왼쪽
  └─ 🔁 4번: ⬆️ 위
```

**획득 별**:
- ⭐⭐⭐: 반복 블록 2개 이상 사용
- ⭐⭐: 반복 블록 1개 사용
- ⭐: 도착

**힌트**:
- "4번 같은 패턴이 반복돼요!"
- "반복 안에 반복을 넣을 수도 있어요!"

**학습 포인트**:
- 패턴 인식
- 반복문 중첩 개념

### 스테이지 4: 미로 탈출

**학습 목표**: 복잡한 문제 해결

**스토리**: "정문부터 본관까지 최단거리로 가자!"

**격자판**: 9×9 (벽 있음)
```
🦆 ─→ ┐ ■ ■
■ ■  ↓ ■ ■
■ ■ ←┘ → ┐
■ ■ ■ ■  ↓
■ ■ ■ ■ ←┘
■ ■ ■ ■  │
■ ■ ■ ■  ↓
■ ■ ■ ■ →⭐
```

**제공 블록**: 전체

**미션**: 벽을 피해 최단거리로 이동

**정답 (예시)**:
```
🔁 2번: ➡️ 오른쪽
🔁 3번: ⬇️ 아래
🔁 3번: ⬅️ 왼쪽
🔁 4번: ⬇️ 아래
🔁 5번: ➡️ 오른쪽
```

**획득 별**:
- ⭐⭐⭐: 반복 블록 사용 + 10개 이하
- ⭐⭐: 15개 이하
- ⭐: 도착

**힌트**:
- "한 방향으로 갈 수 있는 만큼 가보세요"
- "같은 방향은 반복으로 묶을 수 있어요"

**학습 포인트**:
- 복잡한 문제를 단계별로 해결
- 최적화 사고

## 💡 교육적 전략 (Phase 1 강화)

### 1. 능동적 발견 (스테이지 2)
- 학생이 직접 선택 ("힌트 보기" vs "계속하기")
- 발견의 기쁨 제공
- 자기주도 학습 유도

### 2. 점진적 복잡도 증가
- 한 번에 하나씩 새로운 개념 도입
- 이전 스테이지에서 배운 것을 활용

### 3. 실패를 두려워하지 않는 환경
- 무제한 재시도
- 실패 시 격려 메시지
- 힌트 시스템으로 막힘 방지

### 4. 즉각적인 피드백
- 코드 실행 즉시 결과 확인
- 성공/실패를 명확하게 표시
- 별점으로 성취도 시각화
- **에러 위치 명확화** (Phase 1 추가)

### 5. 자기 주도 학습
- 힌트를 선택적으로 사용
- 여러 정답 인정
- 자유 창작으로 마무리

### 6. 게이미피케이션
- 스토리텔링 (인하대 캠퍼스 탐험)
- 별 수집
- 진행률 표시
- 완주 축하

## 📈 예상 완주율

### 기존 (8개 스테이지, 10개 블록)
- 예상 완주율: 60-70%
- 이탈 시점: 스테이지 2 (지루함)

### 개선 (6개 스테이지, 5개 블록)
- 예상 완주율: 80-85%
- 이탈 감소: 능동적 발견 + 부담 감소
