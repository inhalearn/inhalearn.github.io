# UI 디자인 가이드

## 디자인 원칙
1. **모바일 우선** — 세로 모드 최적화. 터치 타겟 최소 44px. 스크롤 최소화.
2. **즉각적 피드백** — 터치 시 0.2초 내 시각적 반응. 실행 즉시 애니메이션.
3. **친근함** — 딱딱한 교육이 아닌 즐거운 놀이. 밝은 색상, 둥근 모서리, 격려 메시지.
4. **단순함** — 한 화면에 모든 것. 복잡한 메뉴 없음. 클릭 3번 이내에 목표 달성.
5. **인하대 정체성** — 스카이블루 컬러, 인덕이 캐릭터로 브랜드 표현.

## Phase 1 우선순위 ⭐
Phase 1 MVP에서 반드시 구현해야 할 UI 컴포넌트:
1. **랜딩 페이지** + 20초 인터랙티브 데모
2. **진행 표시** (화면 상단: 📍 3/6 단계 ⭐⭐⭐ 9개)
3. **속도 조절** (보통/빠르게/건너뛰기)
4. **에러 피드백** (구체적 블록 위치 + 빠른 수정)
5. **발견 모달** (스테이지 2: 반복문 발견 유도)
6. **비교 모달** (5줄 → 2줄 코드 비교)
7. 기본 컴포넌트 (헤더, 캔버스, 블록, 실행 버튼)

## 금지 사항 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| 인하대 공식 느낌 | 우리는 학생 프로젝트. 공식 사이트로 오해받으면 안 됨 |
| 다크모드 | 모바일 야외 사용 시 가독성 떨어짐. 라이트 모드만 |
| 작은 버튼 (< 44px) | 터치 오류 발생. iOS 권장 최소 크기 |
| 글래스모피즘 (backdrop-blur) | AI 템플릿 느낌. 성능 저하 |
| 과도한 애니메이션 | 배터리 소모, 멀미 유발 |
| 자동 재생 동영상/사운드 | 모바일 데이터 낭비, 수업 중 민망함 |

## 애니메이션

### 허용되는 애니메이션
| 애니메이션 | 지속 시간 | Easing | 사용처 |
|-----------|---------|--------|--------|
| Fade In | 0.3s | ease-in-out | 페이지 전환 |
| Slide Up | 0.4s | ease-out | 모달 등장 |
| Scale | 0.2s | cubic-bezier(0.34,1.56,0.64,1) | 블록 추가 |
| Translate | 0.3s | ease-in-out | 인덕이 이동 |
| Rotate | 0.5s | ease-out | 별 획득 |

### 금지되는 애니메이션
- ❌ 무한 반복 애니메이션 (배터리 소모)
- ❌ 3D 변환 (성능 저하)
- ❌ Parallax (멀미 유발)
- ❌ 글로우/블러 애니메이션 (AI 슬롭)

### 인덕이 이동
```css
duration: 0.3s per 칸
easing: ease-in-out
type: translate (x, y)
trail: 이동 경로 선 (점선, #0099CC)
```

## 아이콘

- 이모지 우선 (⬆️⬇️⬅️➡️🔁🎨✏️⭐💬💡)

- 색상: 부모 요소 색상 상속 (currentColor)

### 금지 사항
- ❌ 아이콘을 둥근 배경 박스로 감싸기 (AI 슬롭)
- ❌ 그라데이션 아이콘
- ❌ 너무 얇은 선 (strokeWidth < 1.5, 모바일에서 안 보임)
